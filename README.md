# Pozzer

Decentralized infrastructure protocol focused on DePIN (Decentralized Physical Infrastructure Networks).

---

## 🚀 Overview

Pozzer is designed to enable scalable blockchain infrastructure for real-world applications, allowing users to participate in decentralized networks and earn rewards.

---

## ⚙️ Core Components

• Blockchain infrastructure  
• Node network (Worker / Verifier / Delegators)  
• Smart contracts  
• Web3 payment layer  

---

## 🧠 Architecture

The network is composed of:

• Worker Nodes — provide computational resources  
• Verifier Nodes — validate transactions  
• Delegators — support network security  

---

## 🌐 Ecosystem

• Wallet  
• DEX  
• Payment Gateway  
• Node Dashboard
